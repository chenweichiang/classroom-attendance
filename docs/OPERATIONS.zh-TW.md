# 課堂點名 操作手冊

下面的 `attend.example.edu` 請換成你自己的網域（`.env` 裡 `ATTEND_BASE_URL` 的那個）。老師端主頁 `https://attend.example.edu/t`（課程入口、上課流程、問題處理對照表都在這一頁），學生說明頁 `/help`（不用登入，可以貼給學生），學生備援輸碼頁 `/c`。老師密碼是伺服器 `.env` 裡的 `ATTEND_TEACHER_PASSWORD`。

安裝與部署看 [README](../README.zh-TW.md)；這份只講上課怎麼用。

## 每門課第一次上課：只做綁定

1. 在 `/t` 該課程按「只做綁定（第一次上課用）」，開投影頁。這一場開放 10 分鐘（名冊頁可調 3 到 30 分鐘），不記遲到與缺席、不計入出席率、結束不發 Discord，報表與 CSV 也不會出現這一場。
2. 學生掃 QR，填學號、中文全名、自設 4 到 6 位 PIN 兩次。點名頁看得到誰綁好了。
3. 綁定場次也可以抽點：叫到人不在，那個學號的綁定會被撤回（那筆綁定不是本人做的），而且那個學號這一場不能再綁，代綁的人重掃也綁不回去。本人下次上課再綁：點名頁先按開放「首次綁定」，請他掃碼設定。你若按錯「不在」，處理方式相同。
4. 名單上標「待確認」的看一眼：同一支手機綁了兩個學號、或姓名寫法與名冊不同（同字數、同姓，例如異體字）的都會在這裡，當場問本人。
5. 這一場不能手動改狀態；第一次上課要留出缺勤紀錄，就在綁定結束後另開一場一般點名（學生此時已綁好，掃碼按一下就完成）。
6. 綁定場次還沒結束時按「開始點名」會被擋下來，先結束綁定場次。

## 每次上課（約 4 分鐘）

1. 筆電接投影機，瀏覽器開 `/t`，登入一次（30 天記住；在任何一台按登出，所有裝置都會登出）。
2. 該課程按「開始點名」，進入點名頁；按「開投影頁」，把那個分頁拖到投影幕全螢幕（Mac ⌃⌘F，Windows F11）。投影頁第一次載入會把這台的網路出口記成「教室 IP」；之後用手機開投影頁不會蓋掉，要改就在點名頁按「以這台為教室 IP」。
   投影頁：大 QR 每 10 秒換，換掉之後舊的那張還能用 30 秒（學生從相機辨識到瀏覽器開好，實地中位數約 7 秒）；下方六位數同步換；右上「已簽到／全班」；左下剩餘分鐘。
3. 手機也開 `/t`，進同一場點名頁看名單（每 3 秒更新）。
4. 出席窗（預設 3 分鐘）到了自動關；還有人在簽就趁出席窗內按「延長出席窗」。出席或遲到看的是學生「掃到」的時間，不是送出的時間：窗內掃到、填到過窗才送出的人仍記出席。關窗後到遲到上限（預設 15 分鐘）仍可簽，記遲到；這時按延長只延遲到窗，晚到的不會變出席。
   點名頁的「簽到漏斗」顯示幾支手機掃到、幾支掃到時 QR 已過期、幾人送出、幾人成功；「卡住的人」列出連續被拒兩次以上的學生與原因。人數不動時先看這兩塊，知道是哪一步在掉人。
5. 按「抽點 N 人」：畫面大字顯示學號與姓名，叫名看人，按「在」或「不在」。「在」會把待確認的人升成出席；「不在」改缺席，用同一支手機簽的另一位一起改缺席並標「代簽連坐」。抽點與待確認裁定要在按「結束」之前做完，結束後不能抽。
6. 看「待確認」篩選：同一支手機簽了兩個學號時兩人都在裡面，當場問；放行按「出席」，否則「缺席」。被放行的那位這次沒綁到手機，下次要簽時記得臨時開放首次綁定。
7. 按「結束點名」：沒簽的自動記缺席，名單發到 Discord。請假的在名單上改「請假」。誤按結束就用「刪除此次」整筆撤掉再重開（已發到 Discord 的名單撤不回）。
8. 整場出問題（投影壞掉、網路斷、多數人簽不進來）有兩個動作，都在結束後的點名頁：「自動缺席整批改成…」把系統自動記的缺席一次改成出席、遲到或請假（不動你手動設的與學生自己簽的）；「本場作廢」保留紀錄但不計入出席率、報表與 CSV 不出現，可以取消作廢。

## 學生第一次

投影幕掃 QR，填學號、中文全名、自設 4 到 6 位 PIN 兩次，送出。這支手機從此綁定該學號（識別由伺服器以 cookie 下發，無痕模式或封鎖 cookie 會簽不了）。姓名與名冊字數相同、第一個字相同就放行（異體字不會被擋），但會標「姓名寫法不同」並轉待確認，等你看一眼。
第一週宣布：PIN 只在綁定與換手機時用，要記得、不給人；手機掃不過不要借同學的，直接舉手找老師；換手機找老師；抽點不在就是缺席並記代簽嫌疑，用同一支手機幫忙簽的那位同一次也算缺席；修兩門課要各綁一次。

## 學生之後每次

掃 QR，頁面已顯示姓名，按一下就完成，不用輸 PIN（PIN 只在綁定、換手機、老師解除綁定之後才會用到）。相機掃不到就到 `/c` 輸投影幕上的六位數。代價是拿到別人已解鎖的手機就能替他簽，這一層靠抽點擋。

## 第一週之後：關掉首次綁定

綁定場次不受這個開關影響（一律開放）。全班綁定完成後，到「名冊與設定」把「首次綁定」關掉。之後沒人能用別人的學號綁走手機。新同學或換手機的人要簽時，在點名頁按「首次綁定：已關閉（按一下開放）」臨時打開，簽完再按一次關掉。

## Discord 自動通知

選用功能。在「名冊與設定」填該課的 Discord 頻道 ID、伺服器 `.env` 設好 `DISCORD_TOKEN`（bot 要有該頻道的發言權限）之後，按「結束點名」後，缺席、遲到、待確認名單（學號＋姓名）會自動發到該課頻道；沒收到就在點名頁按「發到 Discord」重發。自動結案而出席不到一半的場次不會自動發（多半是整場出問題，發出去就是公開的誤報），點名頁會顯示一行紅字，確認名單沒問題後再按「發到 Discord」。綁定場次與已作廢的場次不發、也不能手動發。要停用把頻道 ID 清空即可。名單含學號與姓名，頻道請設成只有修課學生與老師看得到。

## 學生自查

學生用綁定的手機開 `/me` 就能看整學期出席率與每次紀錄，不用問老師。

## 備份

系統本身不做備份，請自己排程。資料庫是 `data/attend.db`（SQLite，WAL 模式），直接複製檔案可能拿到不一致的狀態，要用 SQLite 的線上備份取快照。容器的 `/tmp` 是 tmpfs、從外面讀不到，所以快照寫在 `/data` 底下，而且要用容器的服務帳號（uid 10001）做，用 root 開資料庫會留下 root 擁有的 `-shm` 檔：

```bash
cd /path/to/attend
docker compose exec -T -u 10001 attend python3 -c "import sqlite3; s=sqlite3.connect('/data/attend.db'); d=sqlite3.connect('/data/.snapshot.db'); s.backup(d); d.close(); s.close()"
gzip -c data/.snapshot.db > ~/backups/attend_$(date +%Y%m%d).db.gz && rm -f data/.snapshot.db
```

備份檔含學生個資而且是明文，放到雲端之前先加密，並訂好保留期限。還原：

```bash
cd /path/to/attend && docker compose stop
gunzip -c ~/backups/attend_YYYYMMDD.db.gz > /tmp/restore.db
sudo install -o 10001 -g 10001 -m 644 /tmp/restore.db data/attend.db
sudo rm -f data/attend.db-wal data/attend.db-shm /tmp/restore.db
docker compose up -d
```

## 系統自己會做的事

- 遲到窗過了沒按「結束點名」：自動結案並把沒簽的記缺席，報表照常，Discord 也會發（出席不到一半的除外，見上），但發送時間是你下一次打開老師頁的時候。
- 抽點判「不在」：那位改缺席；若他是用別人的手機簽的，同一支手機簽的另一位也改缺席並標「代簽連坐」。
- 掃 QR 開出來的表單在開出來的當下就綁定那支手機，轉貼給別人一律被擋。能轉傳的只剩 QR 本身（最長 40 秒有效），這一層靠一機一人綁定與隨機抽點擋。
- 已結束的點名不能延長；要再點名回主頁重新開始。
- 六位數輸碼每支手機每分鐘最多輸錯 10 次、整個出口 300 次；簽到 API 每支手機每分鐘 12 次、同一個網路出口的未綁定手機合計每分鐘 240 次，已綁定的手機不受出口上限影響。
- 「IP 與教室不同」的標記：一場裡多數人都不是走教室網路（都用行動網路）時，這個標記沒有參考性，點名頁會先不顯示並說明原因；CSV 裡照樣留著。
- 同一場首次綁定滿 5 人之後，不再標「疑似同手機」與「集中綁定」（第一週全班同網路、同型號手機會人人亮），這段期間靠抽點。
- 想知道系統看到的 IP 是什麼（IP 比對標記的依據），開 `/api/ip`。

## 例外處理

| 情況 | 做法 |
|---|---|
| 手機沒電、沒手機 | 點名頁最下方「手動簽到」輸學號 |
| 忘 PIN（平日不用輸，只有換手機或清過瀏覽器資料的人會遇到） | 名冊頁該生按「重設」（清 PIN 與裝置），請他重新掃碼設定 |
| 顯示「PIN 錯太多次」 | 這一場請他找你手動簽到；下一場自動解鎖。剛被解除綁定的學生若被別人亂試 PIN 也會這樣，手動簽到後按「重設」讓他重綁 |
| 換手機 | 名冊頁該生按「解除綁定」，重新掃碼即綁新手機；若首次綁定已關閉，點名頁先按開放 |
| 顯示「學號已綁定另一支手機」 | 這表示曾有人用別支手機以此學號簽過。看名冊頁該學號的綁定時間，問清楚後解除綁定 |
| 名單標「疑似同手機」 | 兩位在 90 秒內從同一網路出口、同型號手機各做了第一次綁定。同型號手機在校園 Wi-Fi 上指紋相同，所以只是提示；看一眼兩位是不是各拿一支手機 |
| 一個人標「裝置已綁他人」 | 這支手機曾用來首次綁定另一個學號，多半是代簽者的手機。到名冊頁看哪兩個學號綁在同一天，把不該綁的那個「解除綁定」 |
| 剛加選、不在名冊 | 先在紙上記；課後更新名冊（下段）後回那次點名頁用「手動簽到」補登 |
| 網路壞掉 | 改口頭點名；系統沒有離線或區網備援模式 |

## 名冊更新

1. 本機整理 CSV（欄位 student_id、name、class），放 `data/rosters/`（這個目錄不進版控）。`scripts/parse_rosters.py` 是範例：`python3 scripts/parse_rosters.py --nthu-csv 清大選課名單.txt --ntub-xls PoolExport.xls`（清大用校務資訊系統匯出的選課名單文字檔；北商 PoolExport 一個檔可能含兩門課）。別的學校照自己的匯出格式改。
2. 上傳並匯入（重複執行安全：同學號只更新姓名班級，不動 PIN 與綁定；加 `--prune` 才刪名冊裡沒有的人）：

```bash
cat data/rosters/demo.csv | ssh 你的主機 'cd /path/to/attend && docker compose exec -T attend python manage.py import-roster --code DEMO --name "示範課程" --csv /dev/stdin'
```

不寫進伺服器磁碟。`--prune` 會連同被移除者的簽到紀錄一起刪，一般不要加。

有人退選、確定要從名冊拿掉時才加 `--prune`（先看他有沒有要保留的簽到紀錄）。名冊有新同學時，姓名用字可能不在自架仿宋字型裡，收據上那幾個字會退回系統明體；要補就跑 `tools/subset_font.py`（說明在檔頭）再部署，字型網址帶內容雜湊，部署後立即生效。

課程代碼（`--code`）自己取，英數字即可，例如 `DEMO`；`python manage.py list` 會列出現有的課程、名冊人數與已綁定人數。

## 學期末

先把每一場的「待確認」裁定完（沒裁定的不算出席但算分母），再到「學期報表」看出席率，「下載 CSV」登校務系統。

要清資料有兩種：只刪某門課（保留其他課與綁定）用 `docker compose exec -T attend python manage.py delete-course --code DEMO`；整個清空（所有課、名冊、綁定、PIN 都消失，下學期重匯名冊、全班重綁）：

```bash
cd /path/to/attend && docker compose stop; sudo rm -f data/attend.db data/attend.db-wal data/attend.db-shm data/.snapshot.db*; docker compose up -d
```

data 目錄是容器帳號 10001 的，不用 sudo 刪不掉。**學期中絕對不要更換伺服器 .env 裡的 ATTEND_SECRET**：裝置雜湊用它衍生，一換全班綁定同時失效；要讓老師 cookie 失效用「登出」即可。

## 設定可調

名冊頁最上面：開放分鐘、遲到上限、綁定場次分鐘、QR 秒數、過期容許秒數（預設 30）、抽點人數、IP 比對開關。每門課各自一組。預設值只對新建的課生效；已經存過設定的課要自己改，或用 `manage.py set --code 課程代碼 --key qr_grace --value 30`。
